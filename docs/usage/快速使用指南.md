# 🚀 SDG项目快速使用指南

## 📋 项目概述

本项目包含了完整的SDG（Synthetic Data Generator）使用示例，按功能分类整理，包含：
- **25个文件**，分布在**9个文件夹**中
- **9个Python脚本**，可直接运行
- **9个详细文档**，包含使用说明
- **3个数据文件**，展示生成效果
- **2个配置模板**，快速配置环境

## 🎯 快速开始路径

### 1️⃣ 新手入门
```
基础示例/ → quick_start.py
```
- 最简单的SDG使用示例
- 自动下载演示数据
- 5分钟快速体验

### 2️⃣ 话单数据合成
```
话单数据合成/ → simple_custom_example.py
```
- 使用您的话单测试数据
- 生成507行合成数据
- 质量分数：80.3/100

### 3️⃣ 质量评估
```
质量评估/ → quick_quality_check.py
```
- 快速评估合成数据质量
- 生成可视化对比图
- 提供改进建议

### 4️⃣ 大模型使用
```
大模型配置/ → llm_synthetic_example.py
```
- 支持OpenAI GPT、GLM等
- 需要配置API密钥
- 适合小数据集

### 5️⃣ DeepSeek本地部署
```
DeepSeek本地部署/ → deepseek_local_example.py
```
- 本地部署DeepSeek模型
- 数据隐私保护
- 无API费用

## 🔧 环境配置

### 基础环境
```bash
# 激活SDG环境
cd synthetic-data-generator
source venv/bin/activate

# 返回项目目录
cd ../SDG项目文件/
```

### 大模型环境
```bash
# 复制配置模板
cp 配置模板/env_template .env

# 编辑配置文件
nano .env
# 填入您的API密钥
```

### DeepSeek本地环境
```bash
# 复制DeepSeek配置
cp 配置模板/deepseek_env_template .env

# 启动本地服务（需要先部署）
ollama serve  # 或 vLLM服务
```

## 🎯 使用场景推荐

### 场景1: 快速体验SDG
```bash
cd 基础示例/

```

```bash
cd 话单数据合成/
python simple_custom_example.py

cd DeepSeek本地部署/
python deepseek_local_example.py
```
