# 静态原型稿

> 基于《系统原型设计》文档整理，采用文本线框形式描述核心页面布局，供视觉设计与实现参考。

## 1. 登录页

┌───────────────────────────────┐
│ Logo 区                       │
├───────────────────────────────┤
│           登录标题            │
│ [ 输入框：邮箱/账号 ]         │
│ [ 输入框：密码 ]              │
│ [ 勾选框 ] 记住我             │
│ [ 按钮 ] 登录                 │

```

## 5. AI 仿真数据生成模块
### 5.1 模块入口页
```
┌─────────────────────────────┐
│ 顶部返回首页 / 面包屑        │
├─────────────────────────────┤
│ 标题：AI 仿真数据生成        │
│ 描述：使用行业模板快速生成合成数据 │
│ [ 卡片列表 ] 行业模板预览    │
│ ┌──────────┐ ┌──────────┐ ... │
│ │ 金融      │ │ 通信      │     │
│ │ 数据示例+说明 │ │ 数据示例+说明 │ │
│ │ [按钮] 使用模板 │ │ [按钮] 使用模板 │ │
└─────────────────────────────┘
```

### 5.2 字段配置 & 参数页面
```
┌────────────────────────────────────┐
│ 面包屑：首页 > 仿真数据生成 > 字段配置 │
├────────────────────────────────────┤
│ 左侧：字段列表                     │
│ ┌──────────────┐                  │
│ │ 字段名  | 类型 │ [编辑] [删除]   │
│ │ ───────────── │                  │
│ │ 客户ID | 数值 │                  │
│ │ 姓名   | 文本 │                  │
│ │ ...            │                  │
│ └──────────────┘                  │
│ [按钮] 添加字段                    │
│ 右侧：字段详情配置                 │
│ - 类型选择（数值/文本/日期等）      │
│ - 分布/规则设定（范围、枚举、正则） │
│ - 示例值预览                       │
├────────────────────────────────────┤
│ 参数配置区                         │
│ - 模型类型（CTGAN / Copula 等）     │
│ - 相似度滑块 + 动态参数展示         │
│ - 目标行数输入                     │
├────────────────────────────────────┤
│ 操作区                             │
│ [按钮] 开始生成  [按钮] 保存配置    │
└────────────────────────────────────┘
```

## 7. AI 数据脱敏模块
### 7.1 模块入口页
```
┌─────────────────────────────┐
│ 顶部面包屑 + 标题            │
│ 描述：通过仿真或遮蔽方式确保隐私 │
│ [按钮] 上传/选择数据集       │
└─────────────────────────────┘
```

### 7.2 规则配置页
```
┌─────────────────────────────────────────────────────────┐
│ 上方：数据字段列表 + 自动识别结果（图标标注字段类型）    │
│ ┌──────────────┬───────────────┬──────────────┐ │
│ │ 字段名        │ 自动识别类型    │ 推荐方案           │ │
│ │ 姓名          │ 姓名            │ 仿真（生成虚拟姓名） │ │
│ │ 身份证号      │ 身份证号        │ 仿真 / 遮蔽(****)  │ │
│ │ 手机号        │ 手机号          │ 仿真 / 局部掩码    │ │
│ └──────────────┴───────────────┴──────────────┘ │
│ 右侧：规则详情编辑面板                               │
│ - 方案选择：仿真 / 非仿真（遮蔽、掩码、哈希）         │
│ - 仿真配置：调用仿真数据引擎生成类型一致的新值       │
│ - 非仿真配置：设置掩码格式、哈希算法等                │
│ - 示例结果预览                                       │
├─────────────────────────────────────────────────────────┤
│ 底部：批量应用规则、保存方案按钮                       │
└─────────────────────────────────────────────────────────┘
```

### 7.3 执行与结果页
```
┌─────────────────────────────┐
│ 执行进度条 + 处理日志        │
├─────────────────────────────┤
│ 结果预览表格（原值 vs 处理值） │
│ [按钮] 下载脱敏数据           │
│ [按钮] 导出处理报告           │
└─────────────────────────────┘
```

### 8.2 AI 大模型配置

┌──────────────────────────────────────────┐
│ 标题：AI 大模型配置                      │
│ [ 下拉 ] 服务类型：线上 / 本地           │
│ [ 输入 ] Endpoint                        │

```

### 8.3 邮箱服务器配置
```
┌──────────────────────────────────────────┐
│ 标题：邮箱服务器配置                      │
│ [ 输入 ] SMTP 服务器地址                 │
│ [ 输入 ] 端口                            │

│ [ 输入 ] 发件人邮箱                      │

```
