# 系统原型设计

## 信息架构
- **未登录状态**：默认进入 `登录页`。
- **登录后（普通用户）**：可访问 `首页` 及与角色相关的业务模块。
- **登录后（管理员）**：除普通用户权限外，可访问 `系统设置`（AI 大模型配置、邮箱配置）。

## 页面与交互原型

### 1. 登录页
- **目标**：用户认证入口。
- **组件**：账号输入框、密码输入框、登录按钮、注册入口链接、忘记密码链接。
- **流程**：
  1. 用户输入账号密码，点击登录。
  2. 系统校验，通过后按角色跳转：管理员/普通用户 → 首页。
  3. 新用户可点击注册链接，进入注册流程。

### 2. 注册页
- **目标**：新用户创建账号。
- **组件**：邮箱、手机号（可选）、密码设置、确认密码、注册按钮。
- **交互**：
  - 提交后向用户邮箱发送激活码。
  - 页面可提示“请查收邮箱输入激活码完成激活”。

### 3. 激活页 / 激活弹窗
- **目标**：输入激活码完成账号激活。
- **组件**：激活码输入框、提交按钮、重新发送按钮。
- **交互**：管理员可在后台重发激活邮件。

### 4. 首页
- **目标**：统一入口页。
- **布局**：顶部导航（Logo、用户名、角色、退出按钮）、主区域三大卡片入口。
- **模块卡片与详细页面**：
  1. **AI 仿真数据生成**
     - **入口页组件**：流程说明、行业模板示例、立即进入按钮。
     - **详细页面结构**：
       - 行业模板区：按照行业分类展示可选模板（金融、通信、零售等），提供模板预览与说明。
       - 字段配置区：支持新增/编辑字段、设置字段类型（数值、文本、日期等）、定义取值范围或分布规则。
       - 参数配置区：选择模型类型、相似度滑块、生成行数、训练参数展示。
       - 生成反馈区：实时日志/进度条、生成完成后展示预览按钮与下载按钮。
       - 预览弹窗：原始模板与生成数据双 Tab，支持搜索、分页、下载。
  2. **AI 数据质量评估**
     - **入口页组件**：评估简介、常见指标示例、立即进入按钮。
     - **详细页面结构**：
       - 数据输入区：上传原始数据或选择历史数据集。
       - 指标选择区：勾选相关性、分布相似度、缺失率等指标，设置阈值。
       - 评估执行区：显示运行状态、进度、预计耗时。
       - 结果展示区：仪表盘图表、指标明细列表、问题数据样本、导出报告按钮。
  3. **AI 数据脱敏**
     - **入口页组件**：脱敏说明、适用场景示例、立即进入按钮。
     - **详细页面结构**：
       - 数据上传区：支持上传原始数据或选择已上传文件。
       - 规则配置区：字段列表、自动识别字段类型（如身份证号、手机号、姓名等），基于类型提示两类方案——**仿真方案**（使用 AI 合成数据替换原值，达到脱敏效果）和 **非仿真方案**（遮蔽、掩码、哈希等），默认推荐仿真方案并允许切换或手动调整配置细节。
       - 执行区：运行日志、处理进度、异常提醒。
       - 结果输出区：脱敏后数据预览、下载按钮、生成处理记录。

### 5. 系统设置（管理员）
- **可达入口**：顶部导航“系统设置”按钮，仅管理员显示。
- **子页面或 Tab**：
  1. **AI 大模型配置**
     - API 类型选择（云端、本地）
     - 访问密钥、Endpoint、模型选择等表单
     - 连接测试按钮（实时反馈）
  2. **邮箱服务器配置**
     - SMTP 服务器地址、端口、加密方式
     - 发件人邮箱、授权码
     - 测试邮件发送表单（目标邮箱输入 + 发送按钮）
- **权限控制**：普通用户访问该路径返回 403 页面或重定向到首页。

## 角色与权限流转
- **管理员**
  - 可查看/配置系统设置
  - 可管理用户（激活、重置密码等，可在后续迭代设计）
  - 使用首页三个工具入口
- **普通用户**
  - 使用首页三个工具入口
  - 无系统设置入口

## 设备与响应式建议
- 桌面端为主，保留自适应栅格布局。
- 登录/注册页面在移动端保持单列居中布局。
