# 前后端架构设计文档

## 1. 系统概述

### 1.1 项目简介
AI 数据平台是一个基于 Web 的合成数据生成、质量评估和数据脱敏系统。系统采用前后端分离架构，前端负责用户交互界面，后端提供 RESTful API 服务和业务逻辑处理。

### 1.2 技术栈

#### 前端技术栈
- **框架**: 原生 HTML/CSS/JavaScript（原型阶段）
- **UI 框架**: 自定义 CSS 框架（基于控制台风格）
- **HTTP 客户端**: Fetch API / XMLHttpRequest
- **状态管理**: 本地存储（LocalStorage/SessionStorage）
- **构建工具**: 无需构建（静态页面）或可集成 Webpack/Vite

#### 后端技术栈
- **Web 框架**: Flask (Python)
- **ORM**: SQLAlchemy
- **数据库**: SQLite / PostgreSQL（可选）
- **数据科学库**: 
  - Pandas（数据处理）
  - NumPy（数值计算）
  - SDGX（合成数据生成）
- **认证**: Flask-Login / JWT
- **邮件服务**: smtplib / Flask-Mail

#### 2.3.2 后端分层架构

**1. 路由层 (Routes)**
- 接收 HTTP 请求
- 参数验证
- 调用业务逻辑层
- 返回响应

**2. 业务逻辑层 (Services)**
- 核心业务逻辑处理
- 调用数据访问层
- 调用第三方服务（SDGX、邮件等）
- 异常处理

**3. 数据访问层 (Models)**
- 数据库操作
- ORM 映射
- 数据模型定义

**4. 工具层 (Utils)**
- 通用工具函数
- 数据验证
- 装饰器（权限检查、日志记录等）

## 3. 数据流设计

### 3.1 用户认证流程

```
用户输入 → 前端验证 → API 请求 → 后端验证 → 数据库查询
    ↓
生成 Token → 返回前端 → 存储 Token → 跳转首页
```

### 3.2 合成数据生成流程

```
选择模板/上传数据 → 配置字段 → 设置参数 → 提交任务
    ↓
后端接收 → 数据预处理 → SDGX 模型训练 → 生成数据
    ↓
后处理 → 存储结果 → 返回任务ID → 前端轮询状态
    ↓
任务完成 → 返回结果 → 前端展示/下载
```

### 3.3 数据质量评估流程

```
上传原始/合成数据 → 选择评估指标 → 提交评估任务
    ↓
后端接收 → 数据加载 → 指标计算 → 生成报告
    ↓
存储报告 → 返回结果 → 前端可视化展示
```

## 4. 数据库设计

### 4.1 核心表结构

#### 用户表 (users)
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    role VARCHAR(20) DEFAULT 'user',  -- 'user' | 'admin'
    status VARCHAR(20) DEFAULT 'pending',  -- 'pending' | 'active' | 'disabled'
    activation_code VARCHAR(100),
    activation_expires_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_login_at DATETIME
);
```

#### 任务表 (tasks)
```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    task_type VARCHAR(50) NOT NULL,  -- 'synthesis' | 'quality' | 'masking'
    task_name VARCHAR(255),
    status VARCHAR(20) DEFAULT 'pending',  -- 'pending' | 'running' | 'completed' | 'failed'
    config TEXT,  -- JSON 格式存储配置
    result_path VARCHAR(500),  -- 结果文件路径
    error_message TEXT,
    progress INTEGER DEFAULT 0,  -- 0-100
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    completed_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 系统配置表 (system_configs)
```sql
CREATE TABLE system_configs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    config_key VARCHAR(100) UNIQUE NOT NULL,
    config_value TEXT,  -- JSON 格式
    config_type VARCHAR(50),  -- 'ai_model' | 'email' | 'other'
    description TEXT,
    updated_by INTEGER,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (updated_by) REFERENCES users(id)
);
```

#### 操作日志表 (operation_logs)
```sql
CREATE TABLE operation_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    action VARCHAR(100) NOT NULL,
    resource_type VARCHAR(50),  -- 'task' | 'config' | 'user'
    resource_id INTEGER,
    details TEXT,  -- JSON 格式
    result VARCHAR(20),  -- 'success' | 'failure'
    ip_address VARCHAR(50),
    user_agent TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 5. 安全设计

### 5.1 认证与授权

**认证机制**
- 基于 Session 或 JWT Token
- 密码使用 bcrypt 加密存储
- 激活码有效期 30 分钟

**授权机制**
- 基于角色的访问控制（RBAC）
- 管理员权限：系统设置、用户管理
- 普通用户权限：业务功能使用

### 5.2 数据安全

**数据传输**
- 使用 HTTPS 加密传输
- 敏感数据（密码、API Key）不在前端明文显示

**数据存储**
- 密码哈希存储
- API Key 加密存储
- 用户数据隔离（按 user_id 过滤）

### 5.3 接口安全

**请求验证**
- CSRF Token 保护
- 请求频率限制
- 参数验证和过滤

**错误处理**
- 不暴露敏感错误信息
- 统一错误响应格式

## 7. 部署架构

### 7.1 开发环境
```
前端: 静态文件服务器（nginx 或 Python http.server）
后端: Flask 开发服务器
数据库: SQLite
```

### 7.2 生产环境
```
前端: Nginx 静态文件服务
后端: Gunicorn + Flask
数据库: PostgreSQL
任务队列: Celery + Redis
文件存储: 本地文件系统或对象存储（OSS/S3）
```

### 7.3 Docker 部署
```dockerfile
# 前端容器
FROM nginx:alpine
COPY frontend/ /usr/share/nginx/html/

# 后端容器
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY web_interface/ .
CMD ["gunicorn", "app_complete:app", "-b", "0.0.0.0:5000"]
```
