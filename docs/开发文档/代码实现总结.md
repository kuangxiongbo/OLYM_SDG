## 技术特性

### 1. 异步任务处理
- 使用Python线程池实现异步任务
- 支持长时间运行的任务（数据生成、评估、脱敏）
- 实时进度更新机制

### 2. 数据安全
- 密码使用bcrypt加密
- API Key和授权码使用Fernet加密存储
- 敏感数据不在前端明文显示

### 3. 权限控制
- 基于角色的访问控制（RBAC）
- 管理员权限装饰器
- 用户数据隔离

### 4. 操作审计
- 自动记录关键操作日志
- 记录操作人、时间、IP、结果等信息
- 支持多条件查询

### 5. 错误处理
- 统一的错误响应格式
- 详细的错误信息记录
- 异常回滚机制

## 待优化项

1. **模板数据管理**
   - 当前模板数据为硬编码，建议迁移到数据库或配置文件

2. **异步任务优化**
   - 当前使用线程池，生产环境建议使用Celery + Redis

3. **文件存储优化**
   - 当前使用本地文件系统，建议支持对象存储（OSS/S3）

4. **报告生成**
   - 质量评估报告目前只支持JSON格式，建议支持PDF/HTML格式

5. **字段识别优化**
   - 脱敏字段识别使用规则匹配，建议引入机器学习模型提高准确率

6. **仿真脱敏**
   - 当前使用简单替换，建议使用SDGX生成真实仿真数据

## 启动说明

1. 安装依赖：
```bash
cd web_interface
pip install -r requirements.txt
```

2. 配置环境变量（可选）：
```bash
export SECRET_KEY=your-secret-key
export DATABASE_URL=sqlite:///ai_data_platform.db
export MAIL_SERVER=smtp.qq.com
export MAIL_PORT=465
export MAIL_USERNAME=your-email@qq.com
export MAIL_PASSWORD=your-auth-code
```

3. 启动应用：
```bash
python app.py
```

4. 访问应用：
- API基础路径: http://localhost:5000/api
- 详细接口文档: `docs/开发文档/前后端接口文档.md`
