# 前后端接口文档

## 1. 接口规范

### 1.1 基础信息
- **Base URL**: `http://localhost:5000/api`
- **协议**: HTTP/HTTPS
- **数据格式**: JSON
- **字符编码**: UTF-8

### 1.2 统一响应格式

**成功响应**
```json
{
  "success": true,
  "data": {},
  "message": "操作成功"
}
```

**失败响应**
```json
{
  "success": false,
  "error": "错误信息",
  "code": "ERROR_CODE"
}
```

### 1.3 状态码
- `200`: 成功
- `400`: 请求参数错误
- `401`: 未授权（需要登录）
- `403`: 无权限（权限不足）
- `404`: 资源不存在
- `500`: 服务器内部错误

### 1.4 认证方式
- **Session 认证**: 使用 Cookie 存储 Session ID
- **Token 认证**: 使用 Authorization Header
  ```
  Authorization: Bearer <token>
  ```

  }

### 3.4 生成合成数据

**接口**: `POST /api/synthesis/generate`

**请求头**: 需要认证

**请求参数**
```json
{
  "template_id": 1,  // 可选，使用模板
  "file_id": "file_123456",  // 可选，使用上传的文件
  "fields": [  // 字段配置
    {
      "name": "customer_id",
      "type": "string",
      "action": "regenerate"  // regenerate | keep | remove
    },
    {
      "name": "age",
      "type": "integer",
      "range": [18, 80],
      "action": "regenerate"
    }
  ],
  "model_type": "ctgan",  // ctgan | gaussian_copula | tvae
  "model_config": {
    "epochs": 50,
    "batch_size": 500,
    "similarity": 0.8
  },
  "data_amount": 1000  // 生成数据行数
}
```

**响应示例**
```json
{
  "success": true,
  "data": {
    "task_id": "task_123456",
    "status": "pending",
    "message": "任务已创建，正在处理中"
  }
}
```

**接口**: `POST /api/masking/detect-fields`

**请求头**: 需要认证

```json

  "file_id": "file_123456"
}
```

**响应示例**
```json

  "data": {
    "fields": [
      {
        "name": "name",
        "detected_type": "name",
        "confidence": 0.95,
        "suggested_strategy": "simulation",  // simulation | masking
        "recommendation": "建议使用AI仿真方案，保持数据可用性"
      },
      {
        "name": "phone",
        "detected_type": "phone",
        "confidence": 0.98,
        "suggested_strategy": "simulation",
        "recommendation": "建议使用AI仿真方案"
      },
      {
        "name": "id_card",
        "detected_type": "id_card",
        "confidence": 0.99,
        "suggested_strategy": "masking",
        "recommendation": "建议使用遮蔽方案，仅保留前3位和后4位"
      }
    ]
  }
}
```

### 5.3 配置脱敏规则

**接口**: `POST /api/masking/configure`

**请求头**: 需要认证

**请求参数**
```json
{
  "file_id": "file_123456",
  "rules": [
    {
      "field": "name",
      "strategy": "simulation",  // simulation | masking | hashing
      "config": {
        "model_type": "ctgan",
        "similarity": 0.8
      }
    },
    {
      "field": "phone",
      "strategy": "simulation",
      "config": {
        "model_type": "ctgan"
      }
    },
    {
      "field": "id_card",
      "strategy": "masking",
      "config": {
        "mask_pattern": "***-****-****-****",
        "keep_prefix": 3,
        "keep_suffix": 4
      }
    }
  ]
}
```

**响应示例**
```json
{
  "success": true,
  "data": {
    "config_id": "config_123456",
    "message": "脱敏规则配置成功"
  }
}
```

## 10. 接口调用示例

### 10.1 JavaScript 示例

```javascript
// 登录
async function login(email, password) {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ email, password })
  });
  const data = await response.json();
  if (data.success) {
    localStorage.setItem('token', data.data.token);
    return data.data;
  } else {
    throw new Error(data.error);
  }
}

// 生成合成数据
async function generateSyntheticData(config) {
  const token = localStorage.getItem('token');
  const response = await fetch('/api/synthesis/generate', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify(config)
  });
  return await response.json();
}

// 查询任务状态
async function getTaskStatus(taskId) {
  const token = localStorage.getItem('token');
  const response = await fetch(`/api/synthesis/tasks/${taskId}`, {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  return await response.json();
}
```

### 10.2 Python 示例

```python
import requests

BASE_URL = 'http://localhost:5000/api'

# 登录
def login(email, password):
    response = requests.post(
        f'{BASE_URL}/auth/login',
        json={'email': email, 'password': password}
    )
    data = response.json()
    if data['success']:
        return data['data']['token']
    else:
        raise Exception(data['error'])

# 生成合成数据
def generate_synthetic_data(token, config):
    headers = {'Authorization': f'Bearer {token}'}
    response = requests.post(
        f'{BASE_URL}/synthesis/generate',
        headers=headers,
        json=config
    )
    return response.json()

# 查询任务状态
def get_task_status(token, task_id):
    headers = {'Authorization': f'Bearer {token}'}
    response = requests.get(
        f'{BASE_URL}/synthesis/tasks/{task_id}',
        headers=headers
    )
    return response.json()
```
