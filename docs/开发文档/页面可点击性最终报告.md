## 技术实现

### 智能路由识别
所有业务路由都支持根据 `Accept` 头自动判断：
- `Accept: text/html` → 返回HTML页面（浏览器访问）
- `Accept: application/json` → 返回JSON数据（API调用）
- 默认 → 返回HTML页面
