## 路由设计

### 智能路由识别
所有业务路由都支持根据 `Accept` 头自动判断：
- `Accept: text/html` → 返回HTML页面
- `Accept: application/json` → 返回JSON数据
- 默认 → 返回HTML页面（浏览器访问）

### 路由优先级
1. 应用级路由（`app.py`）优先检查 `Accept` 头
2. 如果是JSON请求，调用蓝图路由
3. 如果是HTML请求，渲染模板
