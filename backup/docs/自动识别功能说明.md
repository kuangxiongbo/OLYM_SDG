# 字段类型自动识别功能说明

## 功能概述

在字段配置页面添加了"自动识别"选项，允许用户直接让SDGX自动处理字段类型，无需手动定义。

## 实现的功能

### 1. 前端功能

#### 1.1 "全部自动识别"按钮
- 位置：字段列表上方，与其他批量操作按钮一起
- 功能：一键将所有字段设置为自动识别模式
- 操作流程：
  1. 点击"全部自动识别"按钮
  2. 调用后端API `/api/synthesis/analyze-field-types` 获取SDGX识别结果
  3. 将所有字段类型设置为 `'auto'`
  4. 保存SDGX识别的类型作为参考（`sdgx_detected_type` 和 `sdgx_confidence`）

#### 1.2 字段类型选择中的"自动识别"选项
- 位置：字段详情配置面板的"字段类型"下拉框
- 选项：`🤖 自动识别 (SDGX自动处理)`
- 功能：为单个字段启用自动识别模式

#### 1.3 自动识别字段的显示
- 字段列表中显示：`🤖 自动识别` 标签
- 字段详情中显示：
  - 特殊提示信息："此字段将由SDGX自动识别类型，无需手动配置"
  - SDGX识别结果参考（如果已识别）：显示识别类型和置信度
  - 不显示其他配置选项（如取值范围、日期范围等）

### 2. 后端功能

#### 2.1 字段类型识别API
- 端点：`/api/synthesis/analyze-field-types`
- 方法：POST
- 参数：
  - `file_id`（可选）：上传的文件ID
  - `template_id`（可选）：模板ID
- 返回：
  ```json
  {
    "success": true,
    "fields": [
      {
        "name": "field_name",
        "type": "detected_type",
        "confidence": 0.95,
        "type_label": "类型标签",
        "sample_values": ["value1", "value2", "value3"]
      }
    ]
  }
  ```

#### 2.2 生成时的处理
- 如果字段类型是 `'auto'`：
  - **前端**：不传递 `type` 字段给后端
  - **后端**：在识别日期列时，过滤掉 `'auto'` 类型的字段
  - **SDGX**：完全使用自动识别机制处理这些字段

#### 2.3 SDGX自动识别对比（Step 6.8）
- 在传递给SDGX之前，先让SDGX自动识别字段类型
- 与用户配置对比：
  - 如果字段类型是 `'auto'`：跳过对比，记录为自动识别字段
  - 如果字段类型是手动配置：与SDGX识别结果对比，记录不一致的字段
- 输出详细日志，方便用户了解识别结果

## 使用流程

### 方式1：全部自动识别（推荐）

1. 选择数据源（模板或上传文件）
2. 进入"配置字段"步骤
3. 点击"全部自动识别"按钮
4. 系统自动调用SDGX识别所有字段类型
5. 所有字段类型设置为"自动识别"
6. 继续后续步骤，开始生成

### 方式2：单个字段自动识别

1. 选择数据源
2. 进入"配置字段"步骤
3. 点击某个字段的"编辑"按钮
4. 在字段类型下拉框中选择"🤖 自动识别"
5. 保存配置
6. 该字段将由SDGX自动处理

## 优势

1. **简化操作**：无需手动配置每个字段的类型
2. **准确性**：使用SDGX的专业识别机制，确保类型识别准确
3. **一致性**：SDGX训练时使用的类型与识别结果一致
4. **灵活性**：可以混合使用自动识别和手动配置

## 技术实现

### 前端
- `autoDetectAllFields()`: 批量自动识别所有字段
- `autoDetectField(fieldName)`: 单个字段自动识别
- `renderFieldDetail()`: 渲染字段详情，特殊处理 `'auto'` 类型
- `startGenerate()`: 生成时，`'auto'` 类型字段不传递 `type` 配置

### 后端
- `/api/synthesis/analyze-field-types`: 字段类型识别API
- `FieldTypeAnalyzer`: 字段类型分析器，提供准确的类型识别
- `_execute_generation_task_with_app()`: 生成任务执行，过滤 `'auto'` 类型字段
- Step 6.8: SDGX自动识别对比，记录自动识别字段

## 注意事项

1. **自动识别字段不传递类型配置**：
   - 前端生成请求时，`'auto'` 类型字段不包含 `type` 字段
   - 后端在识别日期列时，过滤掉 `'auto'` 类型字段
   - SDGX会完全使用自动识别机制处理这些字段

2. **SDGX识别结果仅供参考**：
   - 前端显示的SDGX识别结果（`sdgx_detected_type`）仅供参考
   - 实际训练时，SDGX会重新识别，可能与参考结果略有不同

3. **混合使用**：
   - 可以部分字段使用自动识别，部分字段手动配置
   - 系统会正确处理混合场景
