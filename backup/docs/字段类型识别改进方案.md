# 字段类型识别改进方案

## 问题分析

### 当前问题

1. **前端识别不准确**：
   - `analyzeFieldType` 函数逻辑简单，只检查前10行数据
   - 日期识别只使用 `Date.parse()`，可能误识别
   - 数值识别只检查是否能转换为数字，不区分整数和浮点数
   - 没有区分日期和日期时间

2. **后端没有充分利用SDGX的自动识别**：
   - 主要依赖用户在前端配置的字段类型（`fields_config`）
   - 没有在传递给SDGX之前，先让SDGX自动识别字段类型
   - 手动配置的类型可能与SDGX自动识别的类型不一致

3. **类型映射不完整**：
   - 前端类型：`numeric`, `text`, `date`, `id`, `pii`
   - 后端类型：`string`, `integer`, `float`, `boolean`, `date`, `datetime`, `discrete`, `id`
   - SDGX类型：通过Inspectors自动识别（`int64`, `float64`, `object`, `datetime64`等）

## 解决方案

### 方案1：改进前端识别逻辑（推荐）

**优点**：
- 用户可以在配置阶段就看到准确的字段类型
- 减少用户手动修改的需要

**实现**：
1. 改进 `analyzeFieldType` 函数：
   - 检查更多样本数据（至少50行）
   - 使用更严格的日期格式匹配（正则表达式）
   - 区分整数和浮点数
   - 区分日期和日期时间
   - 检查字段名的语义（如包含`_id`、`_time`等）

2. 添加后端验证API：
   - 前端上传文件后，调用后端API进行字段类型识别
   - 后端使用pandas和更严格的规则识别字段类型
   - 返回识别结果给前端

### 方案2：使用SDGX自动识别（最佳）

**优点**：
- 完全依赖SDGX的专业识别机制
- 确保类型识别与SDGX训练时使用的类型一致

**实现**：
1. 在传递给SDGX之前，先创建临时DataLoader
2. 调用 `Metadata.from_dataloader()` 让SDGX自动识别字段类型
3. 将SDGX识别的类型与用户配置的类型对比
4. 如果差异较大，提示用户或自动修正

### 方案3：混合方案（推荐）

**结合方案1和方案2**：
1. **前端**：改进识别逻辑，提供初步识别结果
2. **后端**：在传递给SDGX之前，使用SDGX自动识别
3. **对比**：将SDGX识别的类型与用户配置的类型对比
4. **提示**：如果差异较大，在日志中提示，但不强制修改

## 实现步骤

### 步骤1：改进前端识别逻辑

```javascript
// 改进的字段类型识别函数
function analyzeFieldType(data, columnIndex) {
    if (!data || data.length < 2) return 'string';
    
    const sampleValues = data.slice(1, Math.min(51, data.length)).map(row => row[columnIndex]);
    const columnName = data[0][columnIndex];
    
    // 1. 检查字段名语义
    const nameLower = columnName.toLowerCase();
    
    // 2. 日期时间识别（更严格）
    const dateTimePattern = /^\d{4}[-/]\d{1,2}[-/]\d{1,2}(\s+\d{1,2}:\d{1,2}(:\d{1,2})?)?$/;
    const dateCount = sampleValues.filter(val => {
        if (!val || val === '') return false;
        return dateTimePattern.test(String(val).trim());
    }).length;
    
    if (dateCount / sampleValues.length > 0.8) {
        // 检查是否包含时间部分
        const hasTime = sampleValues.some(val => {
            const str = String(val).trim();
            return /\d{1,2}:\d{1,2}/.test(str);
        });
        return hasTime ? 'datetime' : 'date';
    }
    
    // 3. 数值识别（区分整数和浮点数）
    let integerCount = 0;
    let floatCount = 0;
    sampleValues.forEach(val => {
        if (val === null || val === undefined || val === '') return;
        const num = parseFloat(val);
        if (!isNaN(num) && isFinite(num)) {
            if (Number.isInteger(num)) {
                integerCount++;
            } else {
                floatCount++;
            }
        }
    });
    
    const numericCount = integerCount + floatCount;
    if (numericCount / sampleValues.length > 0.8) {
        // 如果主要是整数，返回integer；否则返回float
        return integerCount > floatCount * 2 ? 'integer' : 'float';
    }
    
    // 4. ID字段识别
    if (isIDField(columnName, sampleValues)) {
        return 'id';
    }
    
    // 5. 默认返回字符串
    return 'string';
}
```

```python
def analyze_field_type_backend(series, column_name):
    """后端字段类型识别（更严格）"""
    non_null = series.dropna()
    if len(non_null) == 0:
        return 'string'
    
    sample = non_null.head(100)
    
    # 1. 日期时间识别
    date_pattern = re.compile(r'^\d{4}[-/]\d{1,2}[-/]\d{1,2}$')
    datetime_pattern = re.compile(r'^\d{4}[-/]\d{1,2}[-/]\d{1,2}(\s+\d{1,2}:\d{1,2}(:\d{1,2})?)?$')
    
    date_count = sum(1 for v in sample if date_pattern.match(str(v).strip()))
    datetime_count = sum(1 for v in sample if datetime_pattern.match(str(v).strip()))
    
    if datetime_count / len(sample) > 0.8:
        return 'datetime'
    elif date_count / len(sample) > 0.8:
        return 'date'
    
    # 2. 数值识别
    try:
        numeric_series = pd.to_numeric(sample, errors='coerce')
        numeric_count = numeric_series.notna().sum()
        if numeric_count / len(sample) > 0.8:
            # 检查是否主要是整数
            int_count = (numeric_series == numeric_series.astype(int)).sum()
            if int_count / numeric_count > 0.9:
                return 'integer'
            else:
                return 'float'
    except:
        pass
    
    # 3. ID字段识别
    name_lower = column_name.lower()
    if name_lower.endswith('_id') or name_lower == 'id':
        unique_rate = sample.nunique() / len(sample)
        if unique_rate > 0.9:
            return 'id'
    
    # 4. 默认字符串
    return 'string'
```

### 步骤3：在传递给SDGX之前，使用SDGX自动识别

```python
# 在 synthetic_service.py 中
def _execute_generation_task_with_app(self, task_id, config):
    # ... 前面的步骤 ...
    
    # Step 7.5: 使用SDGX自动识别字段类型（如果未提供fields_config）
    if not fields_config or len(fields_config) == 0:
        print(f"任务 {task_id}: [Step 7.5] 使用SDGX自动识别字段类型...")
        try:
            # 创建临时DataLoader
            temp_connector = self.sdgx_adapter.create_connector(df_for_sdgx, task_id, date_columns)
            temp_dataloader = DataLoader(temp_connector)
            
            # 让SDGX自动识别字段类型
            temp_metadata = Metadata.from_dataloader(temp_dataloader, max_chunk=10)
            
            # 提取识别结果
            sdgx_field_types = {}
            for col_name, col_info in temp_metadata.columns.items():
                col_type = col_info.get('sdtype', 'unknown')
                sdgx_field_types[col_name] = col_type
                print(f"任务 {task_id}: SDGX识别字段 {col_name} 类型: {col_type}")
            
            # 如果用户配置了字段类型，对比并提示差异
            if fields_config:
                for field in fields_config:
                    field_name = field.get('name')
                    user_type = field.get('type')
                    sdgx_type = sdgx_field_types.get(field_name)
                    
                    if sdgx_type and user_type != sdgx_type:
                        print(f"任务 {task_id}: ⚠️ 字段 {field_name} 类型不一致 - 用户配置: {user_type}, SDGX识别: {sdgx_type}")
        except Exception as e:
            print(f"任务 {task_id}: ⚠️ SDGX自动识别字段类型失败: {e}")
```

2. 添加后端验证API（步骤2）

- 用户在前端看到更准确的字段类型
