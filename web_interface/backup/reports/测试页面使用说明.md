# 简单测试页面使用说明

## 一、访问地址

测试页面地址：`http://localhost:4000/api/synthesis/test-simple`

或者通过主页面导航到测试页面。

## 二、功能说明

这是一个简化的测试页面，用于快速测试数据生成功能，对比新架构和旧架构的效果。

### 主要功能
1. **文件上传**：支持CSV、Excel文件上传
2. **生成配置**：设置生成数量和模型类型
3. **任务监控**：实时显示任务状态和进度
4. **结果下载**：下载生成的数据
5. **运行日志**：查看详细的运行日志

## 三、使用步骤

### 步骤1：上传文件
1. 点击上传区域或拖拽文件到上传区域
2. 等待文件上传完成
3. 确认文件信息显示

### 步骤2：配置生成参数
1. 设置生成数量（默认100）
2. 选择模型类型（CTGAN 或 Gaussian Copula）

### 步骤3：开始生成
1. 点击"开始生成"按钮
2. 等待任务创建成功
3. 系统会自动轮询任务状态

### 步骤4：查看结果
1. 任务完成后，可以下载结果
2. 可以查看原始数据对比
3. 查看运行日志了解详细过程

## 四、对比测试建议

### 测试场景1：包含被连接日期时间的数据
1. 准备一个包含被连接日期时间的CSV文件
2. 上传文件
3. 开始生成
4. 观察日志中的日期时间修复过程
5. 验证生成的数据是否正确

### 测试场景2：包含'NAN_VALUE'字符串的数据
1. 准备一个包含'NAN_VALUE'字符串的CSV文件
2. 上传文件
3. 开始生成
4. 观察日志中的清理过程
5. 验证生成的数据是否正确

### 测试场景3：正常数据
1. 准备一个正常格式的CSV文件
2. 上传文件
3. 开始生成
4. 验证生成的数据质量

## 五、日志说明

### 日志类型
- **info**：信息日志（蓝色）
- **success**：成功日志（绿色）
- **error**：错误日志（红色）

### 关键日志点
1. 文件上传成功
2. 任务创建成功
3. 数据准备过程（新架构）
4. 日期时间修复过程
5. 模型训练过程
6. 数据生成过程
7. 任务完成

## 六、故障排查

### 问题1：文件上传失败
- 检查文件格式是否支持（CSV、Excel）
- 检查文件大小是否过大
- 检查服务器日志

### 问题2：任务创建失败
- 检查是否已登录
- 检查API接口是否正常
- 检查服务器日志

### 问题3：任务执行失败
- 查看运行日志中的错误信息
- 检查数据格式是否正确
- 检查日期时间列是否被正确修复
- 检查服务器日志

## 八、注意事项

1. **登录要求**：需要先登录才能使用
2. **文件格式**：支持CSV、Excel格式
3. **数据量**：建议测试数据量不要太大（<1000行）
4. **网络**：确保网络连接正常
5. **浏览器**：建议使用Chrome或Firefox浏览器
