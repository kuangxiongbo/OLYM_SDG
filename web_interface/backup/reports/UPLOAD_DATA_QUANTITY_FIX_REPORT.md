# 上传数据量字段修复报告

## 🐛 **发现的问题**

### ❌ **上传数据标签页缺少数据量字段**
用户反馈：在"上传数据"标签页中没有"数据量"字段，而"演示数据"标签页有。

### 🔍 **问题分析**
- **演示数据标签页**：有 `demoDataSize` 字段 ✅
- **上传数据标签页**：缺少数据量字段 ❌
- **功能不一致**：两个标签页功能不统一

## ✅ **解决方案**

### 🔧 **修复措施**

1. **添加上传数据量字段**：
   ```html
   <div class="row">
       <div class="col-12">
           <div class="mb-3">
               <label for="uploadDataSize" class="form-label">生成数据量</label>
               <input type="number" class="form-control" id="uploadDataSize" value="1000" min="100" max="10000">
               <div class="form-text">基于上传数据生成的合成数据数量</div>
           </div>
       </div>
   </div>
   ```

2. **更新JavaScript逻辑**：
   ```javascript
   // 根据数据源类型获取数据量
   const dataSourceType = $('input[name="dataSourceType"]:checked').val();
   const dataAmount = dataSourceType === 'demo' ? $('#demoDataSize').val() : $('#uploadDataSize').val();
   ```

3. **统一功能体验**：
   - 两个标签页都有数据量字段
   - 字段标签和说明文字一致
   - 默认值都是1000
