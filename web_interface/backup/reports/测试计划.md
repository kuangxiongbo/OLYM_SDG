## 三、测试用例

### 测试用例1：被连接的日期时间值

**输入数据**：
```csv
date_column
2025/4/1 9:282025/4/1 9:592025/4/1 9:50
2025/4/2 10:152025/4/2 10:30
```

**预期结果**：
- 修复为：`2025-04-01 09:28:00`, `2025-04-02 10:15:00`
- 成功传递给SDGX
- 成功生成合成数据

### 测试用例2：混合格式的日期时间

**输入数据**：
```csv
date_column
2025/4/1 9:28
2025-04-02 10:15:00
2025-04-03
```

**预期结果**：
- 标准化为统一格式
- 成功传递给SDGX
- 成功生成合成数据

### 测试用例3：包含'NAN_VALUE'字符串

**输入数据**：
```csv
id_column
123
NAN_VALUE
456
```

**预期结果**：
- 'NAN_VALUE'被清理为pd.NA
- 成功传递给SDGX
- 成功生成合成数据
