# 循环依赖问题修复说明

## 问题描述

在运行数据生成任务时，出现错误：
```
生成失败: 模板数据加载需要通过SyntheticService实例调用
```

## 问题原因

1. `SyntheticService` 依赖 `DataLoader` 来加载数据
2. `DataLoader.load()` 方法会调用 `load_from_template()`
3. `load_from_template()` 需要调用 `SyntheticService._load_template_data()`
4. 这形成了循环依赖：`SyntheticService` → `DataLoader` → `SyntheticService`

## 修复方案

修改 `SyntheticService._execute_generation_task_with_app()` 中的数据加载逻辑：

**修复前**：
```python
original_df = self.data_loader.load(
    file_id=file_id,
    template_id=template_id,
    fields_config=fields_config
)
```

**修复后**：
```python
# 优先从文件加载
if file_id:
    original_df = self.data_loader.load_from_file(file_id)
else:
    original_df = None

# 如果文件加载失败，从模板生成（直接使用SyntheticService的方法）
if original_df is None and template_id:
    original_df = self._load_template_data(template_id, fields_config=fields_config)
```

## 为什么测试通过了？

集成测试 `test_integration.py` 只测试了：
- DataValidator 模块
- DataTransformer 模块
- 数据处理流程

**没有测试**：
- 从模板加载数据的功能
- `DataLoader.load()` 方法

因此测试没有触发循环依赖问题。

## 修复后的数据流程

```
SyntheticService
    ↓
[Step 1] 加载数据
    ├─ 从文件: DataLoader.load_from_file() ✅
    └─ 从模板: SyntheticService._load_template_data() ✅ (直接调用，避免循环)
    ↓
[Step 2-9] 数据处理流程（使用新模块）✅
```

## 验证

修复后，数据生成任务应该能够：
1. ✅ 从文件加载数据（使用 DataLoader）
2. ✅ 从模板生成数据（直接调用 _load_template_data）
3. ✅ 正确处理日期列修复
4. ✅ 成功生成合成数据
