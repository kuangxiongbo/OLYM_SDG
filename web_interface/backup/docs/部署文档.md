# 生产环境部署文档

## 一、部署前准备

### 1.1 环境要求

- **操作系统**: Linux (推荐 Ubuntu 20.04+ 或 CentOS 7+)
- **Python版本**: Python 3.8+
- **数据库**: PostgreSQL 12+ 或 MySQL 8+
- **Web服务器**: Nginx 1.18+
- **应用服务器**: Gunicorn 或 uWSGI
- **反向代理**: Nginx

### 1.2 系统依赖

```bash
# 安装系统依赖
sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv
sudo apt-get install -y postgresql postgresql-contrib  # 如果使用PostgreSQL
sudo apt-get install -y nginx
sudo apt-get install -y git
```

### 1.3 Python依赖

```bash
# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```

## 二、数据库配置

### 2.1 创建数据库

**PostgreSQL:**

```sql
-- 创建数据库
CREATE DATABASE sdg_platform;

-- 创建用户
CREATE USER sdg_user WITH PASSWORD 'your_secure_password';

-- 授权
GRANT ALL PRIVILEGES ON DATABASE sdg_platform TO sdg_user;
```

**MySQL:**

```sql
-- 创建数据库
CREATE DATABASE sdg_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'sdg_user'@'localhost' IDENTIFIED BY 'your_secure_password';

-- 授权
GRANT ALL PRIVILEGES ON sdg_platform.* TO 'sdg_user'@'localhost';
FLUSH PRIVILEGES;
```

### 2.2 数据库迁移

```bash
# 初始化数据库
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

## 三、应用配置

### 3.1 环境变量配置

创建 `.env` 文件：

```bash
# 应用配置
FLASK_APP=app_complete.py
FLASK_ENV=production
SECRET_KEY=your_secret_key_here

# 数据库配置
DATABASE_URL=postgresql://sdg_user:password@localhost/sdg_platform
# 或 MySQL: mysql://sdg_user:password@localhost/sdg_platform

# 文件存储配置
UPLOAD_FOLDER=/var/www/sdg_platform/uploads
RESULTS_FOLDER=/var/www/sdg_platform/results

# 邮件配置
MAIL_SERVER=smtp.example.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your_email@example.com
MAIL_PASSWORD=your_email_password

# AI模型配置
OPENAI_API_KEY=your_openai_api_key
SDGX_PATH=/path/to/sdgx
```

### 3.2 配置文件

编辑 `config.py`，确保生产环境配置正确：

```python
class ProductionConfig(Config):
    DEBUG = False
    TESTING = False
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')
    SECRET_KEY = os.environ.get('SECRET_KEY')
    UPLOAD_FOLDER = os.environ.get('UPLOAD_FOLDER', '/var/www/sdg_platform/uploads')
    RESULTS_FOLDER = os.environ.get('RESULTS_FOLDER', '/var/www/sdg_platform/results')
```

## 四、文件系统配置

### 4.1 创建目录

```bash
# 创建应用目录
sudo mkdir -p /var/www/sdg_platform
sudo mkdir -p /var/www/sdg_platform/uploads
sudo mkdir -p /var/www/sdg_platform/results
sudo mkdir -p /var/www/sdg_platform/logs

# 设置权限
sudo chown -R www-data:www-data /var/www/sdg_platform
sudo chmod -R 755 /var/www/sdg_platform
```

### 4.2 日志目录

```bash
# 创建日志目录
sudo mkdir -p /var/log/sdg_platform
sudo chown -R www-data:www-data /var/log/sdg_platform
```

## 五、Gunicorn配置

### 5.1 安装Gunicorn

```bash
pip install gunicorn
```

### 5.2 创建Gunicorn配置文件

创建 `gunicorn_config.py`:

```python
import multiprocessing

bind = "127.0.0.1:5000"
workers = multiprocessing.cpu_count() * 2 + 1
worker_class = "sync"
timeout = 120
keepalive = 5
max_requests = 1000
max_requests_jitter = 50
preload_app = True
accesslog = "/var/log/sdg_platform/access.log"
errorlog = "/var/log/sdg_platform/error.log"
loglevel = "info"
```

### 5.3 创建Systemd服务

创建 `/etc/systemd/system/sdg-platform.service`:

```ini
[Unit]
Description=SDG Platform Gunicorn daemon
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/sdg_platform
Environment="PATH=/var/www/sdg_platform/venv/bin"
ExecStart=/var/www/sdg_platform/venv/bin/gunicorn \
    --config /var/www/sdg_platform/gunicorn_config.py \
    app_complete:app

Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable sdg-platform
sudo systemctl start sdg-platform
sudo systemctl status sdg-platform
```

## 六、Nginx配置

### 6.1 创建Nginx配置文件

创建 `/etc/nginx/sites-available/sdg-platform`:

```nginx
server {
    listen 80;
    server_name your_domain.com;

    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your_domain.com;

    # SSL证书配置
    ssl_certificate /etc/letsencrypt/live/your_domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your_domain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 日志
    access_log /var/log/nginx/sdg-platform-access.log;
    error_log /var/log/nginx/sdg-platform-error.log;

    # 客户端最大上传大小
    client_max_body_size 100M;

    # 静态文件
    location /static {
        alias /var/www/sdg_platform/static;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 上传文件
    location /uploads {
        alias /var/www/sdg_platform/uploads;
        expires 7d;
        add_header Cache-Control "public";
    }

    # 应用代理
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
    }
}
```

### 6.2 启用站点

```bash
# 创建符号链接
sudo ln -s /etc/nginx/sites-available/sdg-platform /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

### 6.3 SSL证书（Let's Encrypt）

```bash
# 安装Certbot
sudo apt-get install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your_domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 七、部署步骤

### 7.1 代码部署

```bash
# 克隆代码
cd /var/www/sdg_platform
git clone https://github.com/your-repo/sdg-platform.git .

# 或更新代码
git pull origin main

# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行数据库迁移
flask db upgrade

# 重启服务
sudo systemctl restart sdg-platform
```

### 7.2 部署脚本

创建 `deploy.sh`:

```bash
#!/bin/bash

set -e

echo "开始部署..."

# 激活虚拟环境
source venv/bin/activate

# 拉取最新代码
git pull origin main

# 安装依赖
pip install -r requirements.txt

# 运行数据库迁移
flask db upgrade

# 重启服务
sudo systemctl restart sdg-platform

# 重新加载Nginx
sudo systemctl reload nginx

echo "部署完成！"
```

## 九、备份和恢复

### 9.1 数据库备份

```bash
# PostgreSQL备份
pg_dump -U sdg_user -d sdg_platform > backup_$(date +%Y%m%d).sql

# MySQL备份
mysqldump -u sdg_user -p sdg_platform > backup_$(date +%Y%m%d).sql
```

### 9.2 文件备份

```bash
# 备份上传文件和结果文件
tar -czf files_backup_$(date +%Y%m%d).tar.gz /var/www/sdg_platform/uploads /var/www/sdg_platform/results
```

### 9.3 自动备份脚本

创建 `backup.sh`:

```bash
#!/bin/bash

BACKUP_DIR="/var/backups/sdg_platform"
DATE=$(date +%Y%m%d)

mkdir -p $BACKUP_DIR

# 数据库备份
pg_dump -U sdg_user sdg_platform > $BACKUP_DIR/db_$DATE.sql

# 文件备份
tar -czf $BACKUP_DIR/files_$DATE.tar.gz /var/www/sdg_platform/uploads /var/www/sdg_platform/results

# 删除7天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
```

添加到crontab:

```bash
# 每天凌晨2点执行备份
0 2 * * * /var/www/sdg_platform/backup.sh
```

## 十、故障处理

### 10.1 服务重启

```bash
# 重启应用服务
sudo systemctl restart sdg-platform

# 重启Nginx
sudo systemctl restart nginx

# 重启数据库（PostgreSQL）
sudo systemctl restart postgresql
```

### 10.2 回滚步骤

```bash
# 1. 停止服务
sudo systemctl stop sdg-platform

# 2. 恢复代码
cd /var/www/sdg_platform
git checkout <previous_commit>

# 3. 恢复数据库
psql -U sdg_user -d sdg_platform < backup_YYYYMMDD.sql

# 4. 重启服务
sudo systemctl start sdg-platform
```

### 10.3 常见问题

1. **服务无法启动**
   - 检查日志: `sudo journalctl -u sdg-platform -n 50`
   - 检查端口占用: `sudo netstat -tlnp | grep 5000`
   - 检查权限: `ls -la /var/www/sdg_platform`

2. **数据库连接失败**
   - 检查数据库服务状态
   - 检查连接字符串
   - 检查防火墙设置

3. **文件上传失败**
   - 检查目录权限
   - 检查磁盘空间
   - 检查Nginx配置中的`client_max_body_size`
