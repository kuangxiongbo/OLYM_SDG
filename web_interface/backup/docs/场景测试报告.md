  - 正确激活码：激活成功

#### 1.6 登录失败
- **测试步骤**:
  1. 使用错误的密码登录
  2. 使用不存在的邮箱登录
  3. 使用未激活的账户登录
- **预期结果**: 
  - 错误密码/邮箱：返回401错误
  - 未激活账户：返回403错误
- **实际结果**: ✅ **通过**
- **代码位置**: `routes/auth.py:464-491`

#### 1.7 登录失败次数限制
- **测试步骤**:
