## 1. 认证模块 (auth) 检视

### 1.1 路由层 (`routes/auth.py`)

#### 发现的问题：

1. **密码验证不一致**
   - 位置: `routes/auth.py:216`

   - 问题: 使用了 try-except ImportError 来处理可选模型，但逻辑复杂，可能影响性能
   - 严重程度: 中
   - 建议: 将 LoginAttempt 和 CaptchaSession 模型作为必需依赖，简化逻辑

4. **错误处理不完整**
   - 位置: `routes/auth.py:255-261`
   - 问题: 注册失败时只返回错误信息，没有记录日志
   - 严重程度: 低
   - 建议: 添加日志记录，便于问题追踪

5. **邮件发送失败处理**
   - 位置: `routes/auth.py:240-244`
   - 问题: 邮件发送失败只打印错误，不影响注册流程，可能导致用户无法激活
   - 严重程度: 中
   - 建议: 考虑邮件发送失败时的处理策略（重试或提示用户）

### 1.2 服务层 (`services/auth_service.py`)

3. **邮件发送未实现**

#### 发现的问题：

1. **SQL注入防护**: ✅ 使用 ORM，已防护
2. **密码存储**: ✅ 使用 werkzeug 的密码哈希，安全
3. **激活码生成**: ✅ 使用 secrets 模块，安全
4. **会话管理**: ⚠️ 需要检查 Flask-Login 配置
5. **CSRF防护**: ⚠️ 需要确认 WTF_CSRF 是否启用

### 1.4 总结

   - 实现邮件发送功能
